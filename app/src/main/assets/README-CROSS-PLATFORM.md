# 🎨 AetherStudio Elite - Universal Cross-Platform Guide
### Android • iOS (iPhone & iPad) • Windows 10/11 • macOS & Linux

AetherStudio Elite is designed to work seamlessly across all platforms without requiring any paid subscriptions or Firebase accounts!

---

## 📱 1. Android Installation
- **APK Install**: Download `AetherStudio-Elite-debug.apk` or `AetherStudio-Elite-release.apk` directly from the GitHub Releases or GitHub Actions build artifact.
- **Install**: Tap the APK on your device to install. If prompted, allow "Install from Unknown Sources".
- **Features**: Ultra-fast native WebView rendering, Android hardware back gesture support, native Gallery publishing, file sharing, and haptic feedback.

---

## 🍏 2. iOS Installation (iPhone & iPad)
- **Live URL**: Open your repository's GitHub Pages URL (e.g. `https://<username>.github.io/<repo>/`) in **Safari** on your iPhone or iPad.
- **Install to Home Screen**:
  1. Tap the **Share** button (box with upward arrow) at the bottom of Safari.
  2. Scroll down and tap **"Add to Home Screen"**.
  3. Tap **Add**.
- **Experience**: Launches in full-screen standalone mode with no browser URL bars, full offline caching via Service Worker, multi-touch gestures, and Apple Pencil pressure sensitivity!

---

## 💻 3. Windows 10 & 11 Installation
### Option A: Install via Browser (PWA)
1. Open the GitHub Pages URL in **Microsoft Edge** or **Google Chrome**.
2. Look at the right side of the address bar: click the **"Install App"** icon (or menu `...` > *Apps* > *Install this site as an app*).
3. The app is now installed on your Windows PC! It has its own desktop shortcut, Start Menu entry, and window frame.

### Option B: Offline Standalone (No Internet Needed)
1. Extract the downloaded `AetherStudio-Elite-Web-PWA-iOS-Windows.zip`.
2. Double-click `run-windows.bat`.
3. It launches immediately in standalone desktop app mode with 100% local processing!

---

## ⚡ Offline & Privacy Guarantee
- **No Firebase Account Required**: All layers, drawings, history, custom color swatches, and brush presets are stored client-side via IndexedDB and LocalStorage.
- **Zero Cloud Dependence**: You can draw, paint, retouch, generate vector paths, and export without an internet connection.
- **Format Publishing**: Export to PNG, JPEG, SVG Vector Paths, Adobe Photoshop (PSD with layers), and TIFF 300 DPI directly to your device storage.
